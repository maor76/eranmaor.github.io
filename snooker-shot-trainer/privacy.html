  • אין בגיבוי סיסמאות, אמצעי תשלום, אנשי קשר, נתוני מיקום או מפתחות API.
  • המידע נשאר בחשבון הגוגל של המשתמש. הוא אינו מועבר, אינו נמכר ואינו משותף עם אף גורם, כולל המפתח.

הערות אימון בעזרת בינה מלאכותית (Claude)

  • התכונה פועלת רק אם המשתמש הזין מפתח API אישי של Anthropic. המפתח נשמר במכשיר בלבד.
  • כשהמשתמש מבקש הערת אימון, נשלחים לשירות של Anthropic נתוני הסשן כמספרים וטקסט: המדידות של כל מכה, ואם בחר, הערה על מה שהוא עובד עליו והממוצעים של סשנים קודמים שסימן. לא נשלחים סרטונים או תמונות.
  • שלב זה נפרד לחלוטין מהגיבוי לדרייב, ואינו עושה שימוש בהרשאת הדרייב או במידע שהתקבל ממנה.

Privacy policy (English)

  • Snooker Shot Trainer (מאמן סנוקר) is a personal Android app for practising straight snooker shots. It has no server, no user accounts, no ads and no analytics.
  • All recordings, calibrations, pocket markings, session results and settings are stored on the device.
  • If the user connects a Google account, the app requests one scope only: https://www.googleapis.com/auth/drive.file, which grants access to files the app itself created - its own backup folder, named "Snooker Shot Trainer" and visible to the user in Drive, and the files inside it.
  • The app cannot see, read, modify or delete any other file in the user's Drive, including other folders, documents or photos.
  • What is backed up: settings, calibrations, pocket markings and session results (including coaching notes) automatically; marked pictures and the video clips of the shots the user ticked to keep ("save for later"), unless the user turns this off in the app's settings; by default the video clips are uploaded on Wi-Fi only. Full session videos are not backed up. Backups contain no passwords, no payment details, no contacts, no location data and no API keys.
  • The data stays in the user's own Google account and is never transferred, sold or shared with anyone, including the developer.
  • Data obtained through Google APIs is not used for advertising, is not sent to any AI service, and is not used to develop, improve or train generalized artificial intelligence or machine learning models.
  • AI coaching notes: only if the user enters their own Anthropic API key (stored on the device only). When the user asks for a note, the session's measurements are sent to Anthropic as numbers and text, plus, if chosen, a focus note and the averages of earlier sessions the user ticked. No videos or pictures are sent. This step does not use the Drive permission or any data obtained through it.
  • Device permissions: camera to record calibrations and sessions; microphone only for voice commands, recognised by the phone's speech service, with no audio kept; access to videos to analyse a video the user picks; internet only for Drive backups and coaching notes.
  • Retention, deletion and revocation: backup files are kept in the "Snooker Shot Trainer" folder and the data files are updated on every backup. Turn off backup in the app's settings, revoke access at myaccount.google.com/permissions, delete the folder "Snooker Shot Trainer" from Drive and empty the Drive trash, and uninstall the app to remove the local data.
